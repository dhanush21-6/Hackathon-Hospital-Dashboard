# Hackathon-Hospital-Dashboard
📌 Overview
An interactive Power BI dashboard designed to analyze and monitor key hospital performance indicators across patient care, resource utilization, and operational efficiency. Built using Power BI, Power Query, and DAX, with a focus on clean data modeling, calculated measures, and filter-driven interactivity for department- and time-based analysis. 

🎯 Objectives
Track hospital financial performance Monitor patient admissions, discharges, and length of stay Analyze department-wise and diagnosis-wise billing Compare Emergency vs Non-Emergency visits,Enable quick filtering and drill-down analysis.
